# Xingyu Pocket: user guide

1. Install and start
Choose Install on the community play page and follow the official flasher. Installation replaces your current play and may clear existing Wi-Fi, portraits, profiles and records. Save anything you need first. This firmware contains no author's pairing details or personal device configuration.

2. Three keys
On home, short Up opens English; Down or OK opens the app menu. Up/Down selects, OK enters and held OK returns through nested pages. Follow each page's footer for its current actions.

3. Connect without a phone
Open Network settings, scan nearby networks, choose your own 2.4 GHz Wi-Fi and confirm. Password entry starts with digits: Up/Down selects a character, OK adds it, held Up switches digit/lowercase/uppercase/symbol groups and held Down deletes. Select Complete and connect, then OK. Check the connection status. Rescan or use Saved networks to switch later.

4. Phone web setup and portrait
Open Network settings > Phone web setup and keep that device page open. Connect the phone to the displayed Pocket-English hotspot using the password on the device; open http://192.168.4.1 and unlock with the displayed access password. On the same home network, the displayed device IP also works. Scan/select Wi-Fi, edit nickname/signature/city or upload, crop, preview and save a photo. Reselect the original to replace a portrait; soft illustration and clear-photo processing follow the preview and do not promise generative sketch/cyber redrawing. Held OK exits setup and shuts down its web service.

5. English discovery
Choose word cards, listening choices, review or the example challenge. In word cards, choose a topic; Up plays the word, OK flips, Up on the back plays the example and OK again advances. Down stars/unstars the word; follow the footer for other actions. In listening choices, Up/Down moves the highlight and OK submits; select Replay to listen again. Hold Up/Down for volume. Initial playback must finish before submission. Review uses starred and missed words. The first catalog contains 64 words, not a complete course or a learning guarantee.

6. AI Partner: use your own account
Connect to Wi-Fi, open AI Partner, select free chat or a situation and confirm. If an activation code appears, open https://xiaozhi.me on your phone, sign in to your own account, choose Add device and enter the code currently displayed on your own device. Then confirm/retry on the badge. Never use the author's or another person's code or publish your code/token. Starting free chat with OK enables automatic listening after replies; follow the footer to pause/resume or interrupt. English situations provide practice goals: hold Up to change a task and Down to page through longer replies. For a self-hosted service, enter only your own address/token in phone setup.

7. Radio and games
Radio short Up/Down changes volume, held Down/Up selects next/previous station, OK pauses/resumes and held OK exits. Radio needs a stable network and depends on third-party station availability. Open Tetris, Pocket Bunny or Memory Match from the menu and follow the footer.

8. Weather and limits
Stay on home after connecting for weather; change the city in phone setup. Optional AQI may remain -- in 1.0 without hiding temperature/humidity/wind. Radio can buffer; AI depends on its account/service. This distribution provides firmware and documentation, with core source kept private; it is not a buildable source repository.
